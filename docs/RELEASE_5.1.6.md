# Reverse Proxy 5.1.6 — Slow but active WebChat generation

An operator's ChatGPT Web was visibly generating a large answer, but the Agent received request_deadline_exceeded at exactly 240 seconds without a final contract. For UI agent contracts only, the default deadline is now 900 seconds (an explicit smaller caller deadline is still honored). The DOM reader can observe ongoing generation for up to 900 seconds, still bounded by its inactivity watchdog after generation stops. Its progress logger records elapsed/idle time, streaming state and response length without including text. Unrelated DOM mutations are now wakeup hints, not proof of model progress; a persistent visible generating/stop control still counts as active generation. This does not submit or retry the prompt again. Native network transport default remains 240 seconds. CI covers inactive fake page mutations and the bounded active budget.
